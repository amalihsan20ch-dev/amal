# جمعية الأمل والإحسان — البوابة العامة ونظام الإدارة

منصّة Next.js (App Router) + Supabase + Tailwind، تعمل كـ PWA. الألوان مشتقّة من شعار الجمعية، والأرقام مبذورة من تقرير الأعمال.

## التشغيل المحلي
```bash
npm install
cp .env.example .env.local   # املأ القيم
npm run dev
```

## قاعدة البيانات (ملف واحد شامل)
في Supabase → SQL Editor نفّذ **`supabase/database.sql`** مرّة واحدة. آمن للتشغيل المتكرّر (idempotent) حتى على قاعدة منشورة. يتضمّن: الجداول، المحفّزات، RLS، التخزين، الإعدادات، سجلّ النشاط، والبذر.

### ترقية مدير النظام
```sql
update profiles set role='super_admin'
where id=(select id from auth.users where email='YOUR_EMAIL');
```

## بوت تيليجرام (إشعار + إرفاق السيرة)
- ضع `TELEGRAM_BOT_TOKEN` في إعدادات Vercel، و`chat_id` من صفحة **/crm/settings**.
- أنشئ Webhook في Supabase على جدول `volunteers` (INSERT) → `/api/volunteer-webhook` مع ترويسة `x-webhook-secret`.
- عند وجود سيرة ذاتية يُرسل البوت **الملف نفسه** عبر رابط موقّع مؤقت (sendDocument).

## الأقسام
**عام:** رئيسية (Hero, من نحن, البرامج, لوحة الأثر, منحنى النمو, الأعمال, دعوة التطوّع) · /contact · /volunteer/register · استعادة كلمة المرور.
**الإدارة (staff):** /dashboard/admin (نظرة عامة) و /crm/* :
- المستفيدون: بحث/تصفية/ترقيم/تصدير CSV + تغيير الحالة السريع.
- المتبرعون: إجماليات + تفاصيل وسجلّ لكل متبرّع + تصدير CSV.
- المتطوّعون: قبول/رفض + فتح السيرة برابط موقّع + تصفية.
- الأعمال: إضافة/رفع صورة/نشر — تظهر في الموقع العام.
- المهام، المكتبة التدريبية، سجلّ النشاط.
- **(super_admin فقط):** مؤشرات الأثر، الإعدادات.

## الحماية (ثلاث طبقات)
middleware (توجيه + أدوار) + حماية على مستوى الصفحات + **RLS** في قاعدة البيانات. الخصوصية (Do-No-Harm): لا قوائم عامة للمتبرعين/المستفيدين — جداولهم بلا أي سياسة قراءة عامة.

## أوفلاين (PWA)
`next-pwa` يخزّن القشرة والقراءات؛ والكتابات الميدانية عبر صندوق الإرسال (`src/lib/outbox.js`).

## SEO
`sitemap.xml` و`robots.txt` وOpenGraph — عدّل `SITE.url` في `src/lib/site.js` إلى نطاقك.
